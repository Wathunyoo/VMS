# อ่านบัตรประชาชนด้วยเครื่องอ่านบัตร (Smart Card Reader)

เสียบบัตรประชาชนที่เครื่องอ่านบัตร → หน้า Check-in กรอก **ชื่อ-นามสกุล, เลขบัตร** ให้ทันที และเก็บ**รูปจากชิปบัตร**เป็นภาพบัตรของรายการนั้น
(ข้อมูลจากชิปถูกต้องกว่าการสแกนด้วยกล้อง เพราะอ่านจากชิปโดยตรง ไม่ต้องเดาตัวอักษร)

## ทำงานอย่างไร

เบราว์เซอร์อ่านเครื่องอ่านบัตรเองไม่ได้ จึงต้องมี **โปรแกรมเชื่อมเครื่องอ่านบัตร** รันบนคอมพิวเตอร์เครื่องเดียวกับที่เปิดหน้า Check-in

```
เครื่องอ่านบัตร (USB) → โปรแกรมเชื่อม (127.0.0.1:47800) → หน้า Check-in ในเบราว์เซอร์ → บันทึกเข้าระบบ
```

- โปรแกรมเชื่อมรับคำขอเฉพาะจากเครื่องตัวเอง และส่งข้อมูลให้เฉพาะเว็บที่อนุญาต (ตั้งใน `CARD_AGENT_ORIGINS`)
- ส่งให้หน้าเว็บเฉพาะ ชื่อ เลขบัตร คำนำหน้า ชื่ออังกฤษ วันหมดอายุ และรูป — **ไม่ส่งที่อยู่ วันเกิด เพศ**
- ไม่บันทึกข้อมูลบัตรลงเครื่อง · ถอดบัตรแล้วล้างจากหน่วยความจำทันที
- ไม่มีโปรแกรมเชื่อม หน้า Check-in ทำงานตามเดิม (สแกนด้วยกล้อง / พิมพ์เอง)

## เครื่องอ่านบัตรที่ใช้ได้

เครื่องอ่านบัตรแบบ **PC/SC (CCID)** ที่อ่านบัตรประชาชนไทยได้ เช่น ACS ACR39U, Feitian bR301 / R502, Identiv SCR3310
— เสียบ USB แล้วใช้ได้เลยบน macOS และ Windows 10/11 (ไม่ต้องลงไดรเวอร์สำหรับรุ่น CCID ทั่วไป)
ควรซื้อ 1 เครื่องมาทดสอบกับระบบก่อนสั่งจำนวนมาก

## เปิดใช้งาน (เครื่อง Mac ที่ติดตั้งระบบ)

1. เสียบเครื่องอ่านบัตร
2. ดับเบิลคลิก **`เปิดเครื่องอ่านบัตร.command`** (เปิดค้างไว้)
3. เปิดหน้า Check-in → ข้างปุ่ม "สแกนบัตร" จะขึ้นป้ายสีเขียว **"เครื่องอ่านบัตรพร้อม — เสียบบัตรได้เลย"**
4. เสียบบัตร → ข้อมูลถูกกรอก → ตรวจทาน → บันทึก

| ป้ายที่เห็น | ความหมาย |
|---|---|
| (ไม่มีป้าย) | ยังไม่ได้เปิดโปรแกรมเชื่อม หรือเว็บนี้ไม่อยู่ในรายชื่อที่อนุญาต |
| ไม่พบเครื่องอ่านบัตร — ตรวจสาย USB | เปิดโปรแกรมแล้ว แต่ไม่ได้เสียบเครื่องอ่าน |
| กำลังอ่านบัตร… | อย่าเพิ่งดึงบัตร (ประมาณ 2–4 วินาที รวมรูป) |
| ข้อความสีแดง | อ่านไม่สำเร็จ / ไม่ใช่บัตรประชาชน — ถอดแล้วเสียบใหม่ให้สุด |
| ⚠ บัตรหมดอายุแล้ว | ยังบันทึกได้ แต่ควรตรวจเอกสารอื่นประกอบ |

## ลองระบบโดยไม่มีเครื่องอ่านบัตร

```bash
npm run card-agent -- --simulate
```

กด Enter = เสียบ/ถอดบัตรจำลอง (บุคคลสมมติ "มานะ รักเรียน" เลขบัตรขึ้นต้นด้วย 0)

## เปิดหน้า Check-in จากที่อยู่อื่น (เช่น ลิงก์ออนไลน์)

ใส่ที่อยู่เว็บใน `.env`: `CARD_AGENT_ORIGINS="https://ชื่อเว็บของคุณ,http://localhost:3000"`
ลิงก์ Quick Tunnel (`*.trycloudflare.com`) เปลี่ยนทุกครั้งที่เปิดระบบ — ใช้กับเครื่องอ่านบัตรไม่สะดวก ควรใช้โดเมนถาวร หรือเปิดหน้า Check-in ด้วย `http://localhost:3000` บนเครื่องที่รันระบบ

## ยังต้องทำก่อนใช้กับลูกค้าหลายราย

- **ทดสอบกับเครื่องอ่านและบัตรจริง** — ระบบทดสอบกับบัตรจำลองที่ตอบคำสั่งแบบเดียวกับชิปจริงแล้ว แต่ยังไม่ได้เสียบบัตรจริง
- **ชุดติดตั้งสำหรับเครื่องป้อมยาม (Windows)** — ตอนนี้โปรแกรมเชื่อมต้องรันจากโฟลเดอร์ระบบ (ต้องมี Node.js)
  เมื่อย้ายขึ้น Cloud ควรทำเป็นไฟล์ติดตั้ง .exe เดียว ให้เปิดอัตโนมัติเมื่อเปิดเครื่อง

## สำหรับนักพัฒนา

- ถอดรหัสชิป: `src/domain/idcard/thai-smartcard.ts` (APDU, TIS-620, วันที่ พ.ศ.)
- โปรแกรมเชื่อม: `scripts/card-agent.ts` → `src/infrastructure/card-agent/` (PC/SC ผ่าน `@pokusew/pcsclite` ซึ่งเป็น optional dependency)
- หน้าเว็บ: `src/features/id-scan/card-reader.ts` (`useCardReader`) + `components/card-reader-status.tsx`
- โปรโตคอล: `GET /v1/status`, `GET /v1/events` (SSE: `status` · `card` · `error`) — เครื่องอ่านยี่ห้ออื่นที่มีโปรแกรมของตัวเอง ทำตัวแปลงให้ส่งข้อมูลรูปแบบนี้ได้
- ทดสอบ: `npm run test:cardreader`
